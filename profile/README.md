## In English
Open R&D initiative for digital language resources, speech technologies, language models and AI infrastructure for the **Bosnian language**. Led by Kolektiv d.o.o. × Gamatrade d.o.o. (BiH). Full charter: `PROJECT_CHARTER_EN.md`. External resources are referenced, never copied; every dataset carries provenance and license.

## Oblasti
- 🎙️ Speech — ASR, govorni korpus, TTS
- 📊 Benchmarks — ASR, LLM, prevod, OCR, NLP
- 📚 Jezički resursi — korpusi, leksikoni, terminologija
- 🧠 Jezički modeli — embeddings, reranker, prevod, LLM, NER
- 🛠️ Developer ekosistem — API, Python biblioteke, demo

## Pravila
- Vanjski resursi se **referenciraju, ne kopiraju** — svaki dataset ima porijeklo i licencu.
- Bez objave privatnih ili pravno neprovjerenih podataka.
- Partnerstva vrijede samo uz potvrđenu saglasnost.
- Treninzi sa značajnim GPU troškom i produkcijske promjene — samo uz odobrenje.
